# Digital Lending Credit Risk Analysis & Loan Portfolio Dashboard

## Project Type
Finance Analytics / Business Analyst Portfolio Project

## Domain
FinTech - Digital Lending

## Tools Used
- SQL (MySQL)
- Excel
- Power BI

## Objective

The objective of this project is to analyze loan application data and identify factors contributing to loan defaults.

The analysis helps financial institutions:
- Identify high-risk customers
- Monitor loan portfolio performance
- Understand default patterns
- Improve lending decisions
