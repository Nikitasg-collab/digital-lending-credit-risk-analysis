# User Stories

## User Story 1

As a Credit Manager,
I want to view default rates by customer segment,
so that I can identify risky borrowers.


Acceptance Criteria:
- Dashboard displays default percentage
- Users can filter by employment type
- Users can filter by credit score


---

## User Story 2

As a Business Manager,
I want to monitor loan portfolio performance,
so that I can track business health.


Acceptance Criteria:
- Total loans displayed
- Total loan amount displayed
- Default trends available
